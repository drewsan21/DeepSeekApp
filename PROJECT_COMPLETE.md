## 📊 Project Overview

DeepSeek Desktop is a comprehensive Electron-based desktop application that combines:
- DeepSeek Harness integration
- Multi-provider AI support (DeepSeek, Qwen, Custom, Local)
- Browser automation and management
- GitHub integration
- MCP server management
- Skill marketplace
- Project synchronization
- Cross-platform support (Windows, Linux, macOS)

## 🚀 Quick Start

### Installation

**Windows:**
```powershell
# Download and run installer
DeepSeek-Desktop-Setup-0.1.0-alpha-x64.exe
```

**Linux:**
```bash
# Debian/Ubuntu
sudo apt install ./deepseek-desktop_0.1.0-alpha_amd64.deb

# Other Linux
chmod +x DeepSeek-Desktop-0.1.0-alpha-x86_64.AppImage
./DeepSeek-Desktop-0.1.0-alpha-x86_64.AppImage
```

**macOS:**
```bash
# Open DMG and drag to Applications
open DeepSeek-Desktop-0.1.0-alpha-x64.dmg
```

### Development

```bash
# Clone repository
git clone https://github.com/deepseek/deepseek-desktop.git
cd deepseek-desktop

# Install dependencies
pnpm install

# Start development
pnpm dev

# Run tests
./scripts/run-tests.sh

# Build for production
pnpm build
```
